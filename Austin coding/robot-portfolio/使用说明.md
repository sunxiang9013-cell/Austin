# PIT PAL / 车载机器人作品集初稿

6 页 A4 横版，3508 × 2480 px，300 dpi，RGB。项目名称 PIT PAL 暂定。采用暖白、炭黑、赛车橙与柔和绿。

## 文件

- `PSD/`：六个独立的分层 Photoshop 文件，按 01–06 顺序打开。
- `预览/`：六张全分辨率 PNG，可先检查效果。
- `六页总览.png`：六页缩略总览。
- `SVG源文件/`：六页矢量排版源文件，保留文字及路径，供后续矢量编辑使用。

## Photoshop 里怎样修改

每页按标题、图解、照片等分组，共有 200 个文字图层。文字可用文字工具编辑。分析图的图形元素是独立的像素图层，可移动、缩放或替换；精确修改路径请使用 SVG 源文件。

照片占位组以 P01、P05-A 等编号命名。展开对应组，保留最下方的“照片底板”，隐藏斜线、裁切角标及占位说明。使用“文件 → 置入嵌入对象”加入实拍图，将其放在照片底板的正上方，然后创建剪贴蒙版（Alt + Ctrl + G），调整尺寸和裁切。封面的路线和表情是独立装饰组，可按实际照片调整或隐藏。

字体使用 Microsoft YaHei 与 Arial。文件已写入文字图层及预览位图，但本轮 Photoshop 的窗口截图功能超时，未能完成 PS 内打开及文字重排验证。若首次打开提示更新文字图层，请更新并对照 PNG 预览检查位置；修改前建议另存副本。

## 六页内容

1. 项目概览：作品名、个人动机、三项核心功能、成品主视觉。
2. 设计缘起：赛车兴趣 → 简洁座舱体验 → 可回应伙伴；座舱场景与设计机会。
3. 交互与表情：平稳、加速、左转、右转、刹车，以及从运动感知到表情的流程。
4. 系统与性格：小智 AI / 大模型 / 本地表情逻辑，性格设置后台示意与对话语气样例。
5. 从零到一：PCB、打板、结构、外观、打印、装配、代码、调试与喷漆，以及真实迭代记录占位。
6. 成品与下一步：实车安装大图、喷漆细节、交互特写、项目反思与待验证内容。

## 最终提交前需据实补齐

- 作品正式名称、作者、日期、合作分工及个人职责。
- 真实器件型号、传感器能力、框架与服务配置。
- 一次具体的“问题 → 修改 → 测试结果”迭代。
- 动作判断阈值、触发时长、稳定性和对话体验的实测记录。

设计缘起被标记为个人体验与设计假设，并没有虚构访谈或研究数据。表情、系统和后台均是示意；加速 / 刹车需结合加速度计，不能仅靠陀螺仪确认。实拍照片、未经提供的内部结构和测试数据均未伪造。

当前 RGB 文件适合屏幕作品集。若要印刷，请按印厂要求再确认色彩配置与出血。
